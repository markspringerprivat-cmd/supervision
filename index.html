Worum geht es?

Die Gruppen bearbeiten einen Fall aus dem Förderschwerpunkt emotionale und soziale Entwicklung. Im Vordergrund steht nicht nur Jamals Verhalten, sondern ein Konflikt im Teamteaching zwischen einer erfahrenen und einer neuen Lehrkraft.

Hinweis: Dies ist eine Seminarsimulation. Die Website unterstützt Rollenklärung, Notizen, Phasenablauf und Ergebnissicherung.

Prototyp für GitHub Pages · Daten werden lokal im Browser gespeichert, Ergebnisse optional per Google Apps Script übertragen.
