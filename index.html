Worum geht es?

Die Gruppen simulieren eine Gruppensupervision zu einem schulischen ESE-Fall. Ausgangspunkt ist Jamal, ein Schüler mit Förderbedarf im Bereich emotionale und soziale Entwicklung. Der eigentliche Supervisionsanlass ist jedoch ein Konflikt im Teamteaching: Eine erfahrene Lehrkraft arbeitet nach einem festen Interventionsschema, während eine neue Lehrkraft beziehungs- und ressourcenorientierte Methoden einbringen möchte.

Die Supervision soll klären, wie Schulleitung und Lehrkräfte einen gemeinsamen, professionellen Umgang mit Jamal entwickeln können, ohne dass pädagogische Differenzen zu einem dauerhaften Erwachsenenkonflikt werden.

Hinweis: Dies ist eine Seminarsimulation. Die Website unterstützt Gruppenzuweisung, Rollenklärung, Ablaufübersicht, Notizen, Phasenarbeit, Ergebnissicherung und Präsentation.

Prototyp für GitHub Pages · Daten werden lokal im Browser gespeichert, Ergebnisse optional per Google Apps Script übertragen.
